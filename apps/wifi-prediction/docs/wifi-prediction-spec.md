# WiFi予言ギミック 仕様書

ESP32-S3を使った自作マジックギミック。演者がスマホから入力した文章を、観客のスマホのWiFi一覧にSSIDとして表示させる。市販の「Hacker 3.0」系ツールを参考にしているが、コピーではなく独自仕様。

他のマジックアプリ（`apps/` 配下）は純粋なWeb UIだが、本ギミックはESP32-S3ファームウェア＋ESP32自身がホストするローカルWeb UIという別軸の構成。開発者（依頼者）はESP32/Arduino初心者。

## 完成イメージ

```
演者のスマホ → ESP32専用Web UI → 予言文を入力 → ESP32-S3 → WiFi Beacon発信 → 観客のスマホのWiFi一覧に予言内容が表示される
```

WiFi一覧では改行できないため、複数行の予言文は複数SSIDに分割して表示する（例: SSID1「あなたが」/SSID2「考えた人物は」/SSID3「大谷翔平」/SSID4「ですね」）。

## ハードウェア

- Type-C SuperMini系ESP32-S3開発ボード（購入済み・到着済み）。Seeed Studio XIAO ESP32S3ではない
- Arduino IDEでは「ESP32S3 Dev Module」として扱う想定。実際のFlash容量・USB CDC設定・BOOTボタン操作の要否は実機を確認しながら調整する
- 開発中はUSB-C給電。完成後は小型ケース＋小型バッテリーでポケット運用（ケース・バッテリーは未購入）

## 開発方針

- **段階的に進める。最初から完成版・全機能を作らない。** MVPは「スマホで入力した文字がWiFi一覧に表示される」ところまで
- **一工程ずつ確認。** 各工程の実機動作を確認してから次に進む。環境構築・書き込み・実機確認はClaude Codeが画面操作できないため、手順を案内→本人が実行→結果報告→次の工程、のループで進める
- Raw 802.11 Beaconフレーム送信（多数の偽SSID）には最初から進まず、標準の `WiFi.softAP()` → ローカルWeb UI → 複数SSID の順で段階的に到達する
- **初心者向け説明を徹底する。** コードだけでなく「何をしている処理か」を都度説明する
- **エラー対応は固定フォーマット。** 原因 → 確認する場所 → 修正方法 → 修正版コード の順で説明する
- **安定性 > 機能数。** 起動後すぐ使える／操作画面が落ちない／ESP32がフリーズしない／REVEALが確実に動く／STOPで確実に停止する／スマホとの接続が切れにくい、を最優先する

## フェーズ構成

### Phase 1: 基本動作確認
ESP32-S3をPCにUSB接続し、Arduino IDEから単一SSID「NANDEYA_TEST」をSoftAPとして発信し、iPhoneのWiFi一覧で確認する。

### Phase 2: ESP32内Web UI
ESP32自身をWebサーバーとして動作させ、HTML/CSS/JSをESP32内に持たせる（クラウドWebアプリにはしない。インターネット接続なしで完全ローカル動作）。演者のスマホがESP32のWiFiに接続し、ブラウザでESP32内のWeb画面を開き、予言文をESP32へ送信できるところまで。

画面イメージ:
```
NANDEYA PREDICTION
予言内容 [ 大谷翔平 ]
[ SEND ]
[ STOP ]
```

### Phase 3: 複数SSID表示
3→5→10→20→必要なら48個の順で段階的にテストする。48個は絶対条件ではなく、マジックとして安定動作する数を優先する。確認項目:
- iPhone/Androidそれぞれで何個表示されるか
- 表示されるまでの時間・表示順序
- SSIDが消えるまでの時間、Beacon送信間隔
- 周囲にWiFiが多い環境での挙動
- ESP32自体の安定性

### Phase 4: マジシャン向け本番UI
開発用の管理画面ではなく、本番中に数秒で操作できる専用UIにする。操作速度を最優先する。

画面イメージ:
```
NANDEYA PREDICTION
テンプレート: [人物][数字][トランプ][国][誕生日][自由入力]
結果 [ 大谷翔平 ]
[ ▶ REVEAL ]   [ ■ STOP ]
状態表示: READY / REVEALING / STOPPED
```

#### プリセット（テンプレート）
毎回全文を入力しなくて済むよう、`{INPUT}` を結果で置換するテンプレートを用意する。
- 人物: 「あなたが／思い浮かべた人物は／{INPUT}／ですね」
- 数字: 「あなたが／考えた数字は／{INPUT}／です」
- トランプ: 「あなたが／自由に選んだカードは／{SUIT}／{VALUE}」
- 国・誕生日・自由入力も同様の方向性

## Web UIデザイン要件

- スマホ（iPhone Safari）前提、片手操作、大きなボタン、誤タップしにくい
- ダーク系デザイン、横スクロールなし
- 本番中に現在の状態（READY/REVEALING/STOPPED）が一目で分かる表示
- ホーム画面追加・PWA的運用は将来検討
